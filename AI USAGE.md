# AI Usage

AI tools were used as a learning and development aid during this project.

## How AI Was Used

AI was used to:

- Explain machine learning concepts such as classification, train-test splitting, precision, recall, and F1 score.
- Help understand Python and scikit-learn code.
- Suggest and explain preprocessing steps such as One-Hot Encoding.
- Help debug coding errors encountered during development.
- Explain model evaluation results and individual predictions.
- Help organize the project documentation and README.

## Human Contribution

The dataset was selected by me and the code was executed and tested in Google Colab.

I reviewed and understood the suggested code and made the project decisions, including:

- Selecting the features used by the models.
- Excluding `sl_no` because it is only a serial identifier.
- Excluding `salary` because it could cause target leakage.
- Choosing Logistic Regression and Decision Tree as the two models.
- Evaluating the models using precision, recall, and F1 score.
- Examining an example prediction and feature importance.

AI assistance was used to support my learning and development rather than replacing my understanding of the project.
